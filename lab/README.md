# CYBER SHIELD - Cyber Crime Investigation System

## 1. Project Introduction
CYBER SHIELD is an educational C++17 console-based system for managing cyber crime investigations, including case records, suspects, and digital evidence.

## 2. Key Features
- Animated Boot Screen & 3D ASCII Animations
- Case, Suspect, and Evidence Management
- Algorithm Visualization Lab (Searching & Sorting)
- Forensic Text Analysis & Investigation Radar
- Data Persistence & CSV/TXT Report Export

## 3. Technology Stack
- Language: C++17
- Platform: Ubuntu Linux
- Compiler: GCC/G++

## 4. DSA Implementation
- **Array:** Case records storage
- **Singly Linked List:** Digital evidence management
- **Stack:** Investigation activity history
- **Queue:** Pending investigation requests

## 5. Compilation & Execution
- Compilation: `make`
- Execution: `./cyber_shield`
- Clean: `make clean`

## 6. Limitations
- Simulation for educational use only.
- No real network scanning or hacking capabilities.
